# Development Log

Real problems met during development and how they were solved. This log feeds the
"Challenges & Solutions" section of the project report.

| # | Problem | Solution |
|---|---------|----------|
| 1 | `load_csv` raised `StorageError("missing columns")` inside a `try` block that also had `except OSError`. Because `StorageError` inherits from `OSError`, the generic handler caught our own error and re-wrapped it as "Could not read CSV", hiding the real cause. | Added an explicit `except StorageError: raise` clause *before* the `OSError` clause. Lesson: exception handlers are checked in order, and subclasses are caught by parent-class handlers. |
| 2 | First `git push` failed: no HTTPS credential helper configured, and the token stored in `~/.git-credentials` was rejected by GitHub. | Verified SSH access (`ssh -T git@github.com`) and set only the push URL of `origin` to SSH. No history rewrite, no force push. |
| 3 | The first generated sample data showed a *negative* savings rate and all three goals as "missed deadline", because incomes were too low and the data ended in 2025 while the demo runs in 2026. | Re-tuned income/expense ranges and moved the data window to Apr–Sep 2026; verified with `monthly_summary` and `collect_alerts` before committing, and added a test asserting a positive overall balance. |
| 4 | Visual check of `goals_progress.png` showed labels like "(1, 850/3,000)": the dollar signs vanished and the text was italic. Matplotlib treats text between two `$` signs as LaTeX math. | Escaped the dollar signs (`\$`) in labels that contain two amounts, and added a regression test. Negative month-over-month labels were also moved below the points so they no longer overlap the trend line. |
| 5 | CLI tests that patched `builtins.input` still tried to read the real keyboard (pytest: "reading from stdin while output is captured"). `ConsoleApp` used `input_func=input` as a default argument, and default values are evaluated once, when the function is defined. | Defaults changed to `None` and resolved inside `__init__` (`input_func or input`), so the built-in is looked up at call time. Most tests inject a scripted `input` function directly. |
| 6 | Streamlit 1.64 logged a deprecation warning on every chart: `use_container_width` was removed from the API after 2025-12-31 (tutorials still use it). | Replaced every `use_container_width=True` with the current `width="stretch"` and checked the server log was clean. |
| 7 | Same "two dollar signs" problem in Streamlit: `st.markdown` renders `$254.53 of $150.00` as a LaTeX formula. Found by taking a Playwright screenshot of the Budgets tab. | Added `md_escape()` that escapes `$` before rendering alert messages, plus a test. Lesson: money formatting interacts with every text renderer that supports math. |
| 8 | Real screenshots of the Tkinter window (HiDPI screen, `Xft.dpi = 192`) showed Treeview rows overlapping and tiny chart text. Tk scales fonts with the screen but keeps widget sizes (row height, column widths, window size) in raw pixels, and `FigureCanvasTkAgg` resets a figure's dpi when it is displayed. | Measured the real font line height to compute a scale factor, then set the Treeview `rowheight`, column widths and window size from it. Added a `dpi` parameter to every chart function so the GUI renders figures at the screen's dpi (setting the dpi after creating the canvas was overwritten). |
| 9 | The independent audit found that `parse_amount("0.004")` passed the `> 0` check *before* rounding, producing a 0.00 budget or goal that later crashed with `ZeroDivisionError` (the GUI became unusable). | Round first, then validate (`>= 0.01`); regression tests for budgets, goals and transactions. |
| 10 | Valid-but-wrong JSON such as `{"transactions": null}` crashed all interfaces with a `TypeError`, bypassing the corrupted-file recovery. Duplicate ids crashed the Tkinter Treeview (`Item already exists`). | Added `_check_structure()` so a wrong shape is treated exactly like a syntax error (backed up, app starts), moved parsing into a `try/except/else`, and skipped duplicate ids with a warning. CSV import now reads `utf-8-sig` so Excel files with a BOM work. |
| 11 | Capturing the Tkinter window with `import -window <id>` lost the "File" menu bar: Tk draws the menu outside the client area that the window id refers to. | Grab the whole (private Xvfb) screen and crop from the window origin, so the menu bar and any open dialog are included. |
| 12 | Playwright's `hover()` on a Plotly bar timed out: Plotly's transparent drag layer sits above the bars and "intercepts pointer events". | Move the real mouse to the bar's centre (`page.mouse.move`), which is what a user does; the tooltip then appears normally. |
| 13 | The first dashboard captures silently showed "My saved data" (312 transactions) instead of the sample data, because a local `data/my_finances.json` existed. | The capture tool now selects "Sample data" explicitly, so the figures never depend on a personal file. |
